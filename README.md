# অনুশীলন (Onushilon) — MCQ Practice & Exam Flutter App

**অ্যাপের নাম:** অনুশীলন  
**প্যাকেজ আইডি:** `com.onushilon.app`  
**ফ্রেমওয়ার্ক:** Flutter (Android, iOS & Web)

---

## প্রধান ফিচারসমূহ
- **প্রাইভেট লগইন গেট ও ক্লাউড সিঙ্ক:** Firebase Authentication (`study-room-exam` ও `hsc-study-room`) এবং Realtime Database-এর সাথে রিয়েলটাইম সিঙ্ক ও অফলাইন স্টোরেজ।
- **হোম ড্যাশবোর্ড ও প্রোগ্রেস চার্ট:** দেওয়া পরীক্ষা, গড় একুরেসি, প্রশ্নব্যাংকের মোট প্রশ্ন, সেইভড আইটেম এবং বিষয় ও অধ্যায়ভিত্তিক ডুয়াল প্রোগ্রেস বার ও ডোনাট চার্ট।
- **পরীক্ষা ও প্র্যাকটিস হাব:**
  - সরাসরি এক বা একাধিক JSON ফাইল আপলোড বা কোড পেস্ট করে কাস্টম পরীক্ষা।
  - ১৪টি ডিফল্ট HSC বিষয় এবং ১২১টি অফিশিয়াল অধ্যায়সহ ৪-ধাপের প্র্যাকটিস পরীক্ষা সেটআপ (অধ্যায় নির্বাচন, JSON ব্যাংক নির্বাচন, প্রশ্ন সংখ্যা, সময়, নেগেটিভ মার্কিং `-০.২৫` ও পূর্বের ভুল প্রশ্ন ফিল্টার)।
- **লাইভ স্ক্রলিং এক্সাম রুম ও রেজাল্ট ভিউ:** কাউন্টডাউন টাইমার, ফ্লোটিং প্রশ্ন নেভিগেটর, মার্কস/একুরেসি/সময় সামারি, সঠিক/ভুল/স্কিপ ফিল্টার, গণিত ও বিজ্ঞানের সমীকরণ/ভগ্নাংশ/ম্যাট্রিক্স/রাসায়নিক সংকেত, SVG চিত্র, রেফারেন্স এবং সোর্স ব্যাজ।
- **সেইভড সেকশন:** বুকমার্ক করা পরীক্ষা ও প্রশ্ন (রিভিশন মোড এবং ইন্টারেক্টিভ প্র্যাকটিস মোড)।
- **সেটিংস ও ব্যাকআপ:** নতুন JSON প্রশ্নব্যাংক আপলোড/রিনেম/ডিলিট, বিষয় ও অধ্যায় এড/এডিট/ডিলিট এবং সম্পূর্ণ JSON ডাটা ব্যাকআপ ও রিস্টোর।

## কীভাবে প্রজেক্টটি রান ও APK বিল্ড করবেন?

### পদ্ধতি ১: পিসিতে Flutter SDK দিয়ে সরাসরি APK বিল্ড
১. প্রথমে `onushilon_flutter_app.zip` ফাইলটি আনজিপ করুন।
২. টার্মিনালে প্রজেক্ট ফোল্ডারে গিয়ে নিচের কমান্ডগুলো রান করুন:
```bash
flutter create . --project-name onushilon --org com.onushilon
flutter pub get
dart run flutter_launcher_icons
flutter build apk --release
```
৩. বিল্ড শেষ হলে `build/app/outputs/flutter-apk/app-release.apk` পাথে আপনার **অনুশীলন** অ্যাপের ইন্সটলযোগ্য APK ফাইলটি পেয়ে যাবেন।

### পদ্ধতি ২: পিসি ছাড়াই GitHub Actions দিয়ে ফ্রি ক্লাউড APK বিল্ড
এই প্রজেক্টের ভেতর `.github/workflows/build_apk.yml` ফাইল যুক্ত করা আছে। প্রজেক্টটি আপনার একটি GitHub Repository-তে আপলোড করলেই **Actions** ট্যাব থেকে স্বয়ংক্রিয়ভাবে `Onushilon-Release-APK` তৈরি হয়ে যাবে।
